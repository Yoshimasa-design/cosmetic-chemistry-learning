# 画面設計

## 文書情報

- 文書バージョン：Ver.0.1
- 更新日：2026-07-21

---

# 1. 設計方針

本システムは、情報を検索するだけの成分辞典ではなく、
「理解しながら学ぶ教材」として設計する。

そのため、

- 情報量より理解しやすさ
- 一覧性より学習性
- 検索より発見

を重視する。

---

# 2. 画面構成

Ver.0.1では以下の画面を実装する。

|画面|内容|
|------|------|
|ホーム|教材トップ|

|素材詳細|素材情報|
|学習テーマ|学習コンテンツ|
|比較画面|素材比較|
|検索画面|検索|

# 3. ホーム画面

表示内容

・検索ボックス

・カテゴリ

・おすすめ素材

・最近学習した素材

・人気の学習テーマ

・クイズへの入口（将来）

---

# 4. 素材一覧

カード表示とする。

各カードには

・画像

・素材名

・分類

・主要機能

を表示する。

クリックすると詳細画面へ移動する。

---

# 5. 素材詳細画面

表示順

① タイトル

② 構造式

③ 基本情報

④ 化学分類

⑤ 化学構造の特徴

⑥ 性質

⑦ 化粧品中での機能

⑧ 製剤中での役割

⑨ 使用される製品

⑩ 関連素材

⑪ 関連する学習テーマ

⑫ 参考文献
