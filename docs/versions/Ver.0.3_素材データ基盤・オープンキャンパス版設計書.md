# Ver.0.3 素材データ基盤・オープンキャンパス版 設計書

## 1. 概要

Ver.0.3では、化粧品素材を教材として扱うためのデータモデルを確立する。

同時に、2026年7月末のオープンキャンパスで来場者に提示できる、操作可能なデモ版を完成させる。

## 2. 開発目標

- 化粧品素材のデータ型を定義する
- 素材の分類語彙を整理する
- 素材データをTypeScriptで管理する
- 素材一覧ページを実装する
- 素材詳細ページを実装する
- 10種類以上の素材を掲載する
- スマートフォンでも閲覧できるようにする
- オープンキャンパスで安定して使用できる状態にする

## 3. デモ版の利用導線

1. トップページを開く
2. 「素材から学ぶ」を選択する
3. 素材一覧から素材を選択する
4. 素材詳細ページを開く
5. 化学構造、性質、化粧品中での役割を確認する
6. 関連素材や関連学習テーマへ移動する

## 4. Ver.0.3で実装する機能

- 素材データ型
- 素材データファイル
- 素材一覧
- 素材カード
- 素材詳細ページ

- 関連学習テーマの表示

## 5. 今回は実装しない機能

次の機能は将来の拡張を考慮してデータモデルには反映するが、Ver.0.3では画面実装しない。

- 高度な全文検索
- 複数条件による絞り込み
- 素材比較
- クイズ
- 知識グラフの可視化
- 学習履歴
- 管理画面
- 外部データベースとの自動連携

## 6. データ管理方針

Ver.0.3では外部データベースを使用せず、TypeScriptファイル内の静的データとして管理する。

理由は以下のとおりである。

- 型チェックを利用できる
- Gitで変更履歴を管理できる
- オープンキャンパス時の動作が安定する
- 将来的にJSONやデータベースへ移行できる
- 数十種類程度の教材データに適している

## 7. 素材データの主要項目

### 識別情報

- id
- slug
- 日本語名
- INCI名
- 英語名
- 別名

### 化学情報

- CAS登録番号
- 化学式
- 分子量
- SMILES
- InChI

高分子、混合物、天然油脂など、単一化合物として表現できない場合は省略可能とする。

### 分類情報

- 由来
- 化学分類
- 化粧品中での機能

### 物理化学的性質

- 状態
- 極性
- 水への溶解性
- 油への溶解性
- 融点
- 沸点
- 補足事項

### 学習情報

- 概要
- 化学学習ポイント
- 化粧品中での役割
- 製剤中での役割
- 注意事項

### 関連情報

- 関連素材
- 関連学習テーマ
- 配合される製品種別

### メディア情報

- 構造式画像
- 一覧用画像
- 画像代替テキスト

### 出典情報

- 資料名
- URL
- 補足
- 参照日

- 英語名

- 関連素材
- 関連テーマ

- 参考資料

情報が登録されていない項目は表示しない。

## 13. 科学表現の方針

- 高校生にも理解できる文章にする
- 科学的正確性を優先する
- 素材の性質と製品としての効果を区別する
- 化粧品の効能を断定しない
- 医薬品的な表現を避ける
- 由来、製法、純度による違いを必要に応じて注記する
- 出典を確認できるようにする
