# データモデル設計

## 文書情報

- 文書バージョン：Ver.0.1
- 更新日：2026-07-21

---

# 1. 設計方針

本システムでは、すべての情報を「独立したデータ」として管理し、
データ同士をIDによって関連付ける。

この方式により、

- データの再利用
- データの追加
- 将来のデータベース化
- 知識グラフ化

を容易にする。

---

# 2. 基本エンティティ

Ver.0.1では以下の10種類のエンティティを定義する。

| エンティティ | 内容 |
|-------------|------|
| Ingredient | 化粧品素材 |
| ChemicalStructure | 化学構造 |
| Property | 物理化学的性質 |
| Function | 化粧品機能 |
| Product | 製品 |
| FormulationRole | 製剤中での役割 |
| ChemicalClass | 化学分類 |
| Origin | 由来 |
| Reference | 文献 |
| LearningTopic | 学習テーマ |

---

# 3. Ingredient

例

```
ingredient_id
```

例

```
ING0001
```

保持する情報

- 日本語名
- 英語名
- INCI名
- CAS番号
- 化学式
- 分子量
- 一般説明
- アイコン画像
- 構造式画像

# 14. ID命名規則

| 種類 | 接頭辞 |
|------|--------|
| Ingredient | ING |
| Structure | STR |
| Property | PROP |
| Function | FUNC |
| Product | PROD |
| Role | ROLE |
| Class | CLASS |
| Origin | ORG |
| Reference | REF |
| Topic | TOP |

番号は4桁とする。

例

ING0001

ING0002

FUNC0003

PROD0010
