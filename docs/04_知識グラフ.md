# 知識グラフ設計

## 文書情報

- 文書バージョン：Ver.0.1
- 更新日：2026-07-21

---

# 1. 目的

本システムでは、化粧品素材を単独で管理するのではなく、
複数の知識を相互に関連付けた「知識グラフ」として管理する。

知識グラフにより、

- 関連する素材
- 共通する機能
- 共通する構造
- 類似した性質

などを横断的に学習できる。

---

# 2. ノード

知識グラフでは、各情報をノードとして扱う。

主なノードは以下のとおりである。

| ノード | 内容 |
|---------|------|
| Ingredient | 化粧品素材 |
| ChemicalStructure | 化学構造 |
| FunctionalGroup | 官能基 |
| Property | 物理化学的性質 |
| Function | 化粧品機能 |
| FormulationRole | 製剤中での役割 |
| Product | 製品 |
| ChemicalClass | 化学分類 |
| Origin | 由来 |
| LearningTopic | 学習テーマ |
| Reference | 文献 |

---

# 3. リレーション

ノード同士はリレーションで接続する。

---

# 4. リレーション一覧

| リレーション | 意味 |
|--------------|------|
| HAS_STRUCTURE | 構造を持つ |
| HAS_PROPERTY | 性質を持つ |
| HAS_FUNCTION | 機能を持つ |
| USED_IN | 製品に使用される |
| BELONGS_TO | 分類される |
| HAS_ORIGIN | 由来を持つ |
| HAS_REFERENCE | 文献がある |
| LEARNED_IN | 学習テーマに属する |
| RELATED_TO | 関連する |
| SIMILAR_TO | 類似する |
| CONTRASTS_WITH | 対比される |

# 9. 探索学習

利用者は

保湿

↓

↓

↓
