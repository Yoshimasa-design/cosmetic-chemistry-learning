# 1. 技術方針

本システムは教育用Webアプリケーションとして構築する。

初期バージョンではシンプルな構成を採用し、
機能追加に伴って段階的に拡張する。

設計原則

- データと画面を分離する
- コンポーネントを再利用する
- 型安全性を重視する
- 将来のDB移行を考慮する

# 4. データ管理

Ver.0.1ではJSONを採用する。

例

```

 └── ingredients/
      glycerin.json
```

画面はJSONのみを参照し、
データを直接埋め込まない。
